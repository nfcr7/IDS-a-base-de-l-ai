# IDS-a-base-de-l-ai
L’objectif de ce projet est de modéliser un IDS pour aider les administrateurs du système à détecter et à identifier toute violation de la sécurité dans leur organisation afin de les prévenir avant de causer des dommages. Pour cela on étudier les performances des méthodes d’apprentissage machine (ML) et ensuite les trois deeplearning "cnn"rnn"dnn"
